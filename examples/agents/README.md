# Real agent onboarding fixtures

These are executable producers for Tracey's `agent.run` OpenTelemetry contract.
They are used by the live onboarding verifier and can also be run manually.

- `node/run.ts` uses Tracey's Node instrumentation package.
- `python/run.py` uses the official OpenTelemetry Python SDK.
- `generic-otlp/send-run.mjs` sends the same contract directly through
  OTLP/HTTP JSON without a language instrumentation wrapper.

All three read the exact environment block generated by Tracey:
`OTEL_EXPORTER_OTLP_ENDPOINT`, `OTEL_SERVICE_NAME`,
`DEPLOYMENT_ENVIRONMENT`, `TRACEY_TENANT_ID`, and `TRACEY_AGENT_NAME`.
Each produces an `agent.run` root with model and tool children, content, tokens,
cost, status, and latency.
